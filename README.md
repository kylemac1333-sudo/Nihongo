# Nihongo V2 — Pro Foundation

This build upgrades the existing Nihongo prototype into a more product-style foundation.

Included:
- redesigned mobile-first UI
- Home dashboard with goals, missions and learning path
- structured lessons and XP
- Sensei chat
- browser speaking-practice mode where supported
- family leaderboard
- points + shop
- admin foundation
- account onboarding
- PWA manifest + service worker

Important:
- This is still a client-side prototype. Accounts and progress are stored locally.
- Real secure accounts, cross-device sync and real AI require a backend (for example Supabase + an AI provider through a server-side function).
- Never put a private AI API key directly in `app.js`.
