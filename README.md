# Nihongo Learning Main

This is the main product build. The visual language is the playful game-style Nihongo world.

## Admin Customisation Control Room
Admins can change:
- brand name and tagline
- Home hero title and description
- six theme colours
- Home section visibility
- world title/subtitle
- each world zone title, emoji, description and destination
- announcement banner on/off
- text-only or countdown banner
- banner title/message/button
- countdown date and time
- banner button destination
- button visibility
- reset/preview

Settings are saved locally in this prototype. Production should move them into Supabase with admin-only Row Level Security.

The AI backend from V3 remains compatible; no OpenAI key belongs in browser code.
